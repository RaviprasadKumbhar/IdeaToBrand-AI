# IdeaToBrand-AI Documentation

Welcome to the shared project documentation for the Inkloom Hackathon.

## Documentation Structure

- Architecture: System architecture and component responsibilities.
- Setup: Local development environment setup.
- API: Backend API endpoints and request/response formats.
- Database: Database schema and Supabase configuration.
- Team: Member responsibilities and integration guidelines.

## Development Rules

1. Pull the latest changes from main before starting work.
2. Create a separate feature branch for your task.
3. Do not commit API keys, passwords, or private credentials.
4. Submit changes through pull requests.
5. Keep documentation updated when modifying APIs or architecture.

## Environment Setup

Copy .env.example to .env and configure your local credentials.

Never commit the .env file.
